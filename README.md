# Calculadora de Cabo de Cobre

App (PWA) para compra de sucata de cabo de cobre: rendimento pela amostra pesada ou estimado pela medida (vias + bitola / Ø externo), preço de empate, lucro do lote e histórico.

- Arquivo único `index.html`, sem build.
- Funciona offline e instala no celular ("Adicionar à tela inicial").
- Dados de referência: catálogos Cobreflex, Induscabos, CaBR, Corfio, Nexans, Prysmian; resistência máxima IEC 60228 / NBR NM 280.
